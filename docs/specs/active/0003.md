# SPEC-0003：版本明确的 API 示例参考页

## 目标

交付 ECO-V1-M2-S2 首片：消费真实 M2-S1 产物并提供搜索、签名、参数模式与固定源码链接。

## 范围

从 main 70a6bc8 建独立分支；用户授权推进不依赖 v0.46 的独立切片。
API 输入固定 Koven 3386e49e 的 v0.45 两教程产物；保留原 Guide/Tour 的 content-source.json。

## 非目标

不切换现有 Guide 来源，不添加在线执行，不称为完整标准库参考，不复制教程源码或预期输出。

## 行为合同

API 区明确标注独立 v0.45 来源与两教程范围；Guide 仍使用既有设计快照。
从原生成器导入真实 koven.api-examples v1，验证固定来源、产物摘要、教程源码摘要和声明范围后保存到原 generated.json 的 api 字段。
按函数名、签名、参数搜索；详情支持固定深链接。源码与示例链接使用 API 固定提交，不跳到不同版本的站内 Tour。

## 接口变化

增加 /api 路由及 query symbol。api-source.json 固定来源与审核产物摘要。
同步 CLI 增加 --api-source 和 --api-artifact；后续同步保留已验证产物，CI 重新核对 API 来源。

## 失败场景

缺失/不支持schema、摘要不符、源码不符、错误仓库/提交、重复或缺失函数、非法链接不允许发布；不得静默降级为旧来源。
空搜索有明确提示，未知深链接有可返回入口。

## 依赖

上游 SPEC-0348 已在 Koven main 3386e49e 归档，实际 CLI 与两教程执行通过。网站来源身份和生命周期门禁已交付。

## 测试与验收

先写导入负例；npm test、真实双来源导入、npm run build；桌面/手机、键盘、深链接、深色实测及 reduced-motion 规则核查；独立复核及远端CI。

## 完成条件

真实产物可消费且不改变既有内容来源，所有必需验证通过，归档并经最终 PR CI 合并。

## 验收证据

本地及独立审查证据见 [验收记录](../../acceptance/spec-0003.md)；远端 CI 待核。
