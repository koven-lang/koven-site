| 4 | Playground 执行前端 | SITE-V1-M2 | 服务版本与隔离验收；真实结果、stdin／参数、诊断及超限 |
| 5 | 分享和复现界面 | SITE-V1-M2 | 服务案例合同；用户确认，固定版本，不静默替换 |
| 6 | 练习界面 | SITE-V1-M2 | 上游测试过的起点／答案及真实执行；未支持能力不出题 |

实现前每个主题按单一 Goal 拆成正式 Spec；生产方未就绪时保持 draft 并登记 blocker。
