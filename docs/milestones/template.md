# 里程碑模板

复制到 drafts/SITE-V1-Mn.md，首行用实际 metadata 替换本标题；登记库存与对应 Spec 的双向归属。

```json
{"id":"SITE-V1-Mn","kind":"milestone","status":"draft","specs":[],"depends_on":[],"blockers":[],"evidence":[]}
```

metadata 形式为 `<!-- metadata: JSON -->`；正文包含下列非空章节：
目标、范围、非目标、基线、依赖、联合验收、完成条件、验收证据。
每项用二级标题；范围说明生态归属、优先级与必需性。未细化主题先留规划，不预占 Spec。
只有至少两份真实子 Spec 全部 done、前置完成、无 blocker 且证据存在时才可 completed。
